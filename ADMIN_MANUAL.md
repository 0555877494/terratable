## 👥 User Management

### Viewing Users

1. Go to "Users" tab
2. See list of all users
3. Filter by role:
   - All users
   - Customers
   - Delivery agents
   - Admins
4. Search by name or email

### User Details

Click any user to see:
- Full name and email
- Role and permissions
- Join date
- Order history
- Total spent
- Loyalty tier and points
- Last active date

### Editing Users

1. Click "Edit" button
2. Update user information:
   - Name
   - Email
   - Phone
   - Address
3. Change role if needed
4. Click "Save Changes"

### Changing Roles

**Available Roles:**
- **Customer** - Can shop and place orders
- **Delivery Agent** - Can deliver orders
- **Admin** - Full system access

**To change role:**
1. Go to user details
2. Click role dropdown
3. Select new role
4. Confirm change
5. User permissions updated immediately

### Deleting Users

⚠️ **Warning:** This action cannot be undone!

1. Go to user details
2. Click "Delete User"
3. Confirm deletion
4. User account removed
5. All associated data archived

### Bulk Actions

Select multiple users to:
- Export user list
- Send bulk email
- Change roles
- Delete accounts

## 📦 Product Management

### Viewing Products

1. Go to "Products" tab
2. See all products in catalog
3. Filter by:
   - Category
   - Status (in stock/out of stock)
   - Price range
   - Rating
4. Sort by name, price, date, rating

### Adding New Products

1. Click "Add Product" button
2. Fill in product details:

**Basic Information:**
- Product name
- Description
- Category
- Price
- Original price (if on sale)

**Media:**
- Main product image
- Additional images (up to 5)
- Image URLs or upload

**Details:**
- Origin country
- Weight/size
- Stock quantity
- Tags (for filtering)

**Marketing:**
- Badge (New, Sale, Bestseller, Limited)
- Discount percentage
- Featured product (yes/no)

3. Click "Save Product"
4. Product added to catalog

### Editing Products

1. Find product in list
2. Click "Edit" button
3. Update any information
4. Click "Save Changes"
5. Changes reflected immediately

### Deleting Products

⚠️ **Warning:** This will remove product from all orders!

1. Find product in list
2. Click "Delete" button
3. Confirm deletion
4. Product removed from catalog
5. Historical data preserved

### Stock Management

**View Stock Levels:**
- See stock count for each product
- Low stock warnings (< 10 items)
- Out of stock indicators

**Update Stock:**
1. Edit product
2. Update stock quantity
3. Save changes
4. Stock updated immediately

**Stock Alerts:**
- Automatic notifications when stock < 10
- Email alerts for out-of-stock items
- Reorder suggestions

### Bulk Product Operations

**Import Products:**
1. Prepare CSV file with product data
2. Go to "Products" → "Import"
3. Upload CSV file
4. Map columns to fields
5. Review and confirm import
6. Products added to catalog

**Export Products:**
1. Go to "Products" → "Export"
2. Select format (CSV, Excel)
3. Choose fields to export
4. Download file

**Bulk Update:**
1. Select multiple products
2. Choose action:
   - Update prices
   - Change category
   - Update stock
   - Add/remove tags
3. Apply changes
4. All selected products updated

## 📋 Order Management

### Viewing Orders

1. Go to "Orders" tab
2. See all orders in system
3. Filter by:
   - Status (Pending, Confirmed, etc.)
   - Date range
   - Customer
   - Payment method
4. Sort by date, total, status

### Order Details

Click any order to see:
- Order number and date
- Customer information
- Items ordered with quantities
- Payment details
- Shipping address
- Current status
- Tracking information
- Notes and special requests

### Updating Order Status

**Status Flow:**
1. Pending → Confirmed
2. Confirmed → Preparing
3. Preparing → Out for Delivery
4. Out for Delivery → Delivered
5. Any status → Cancelled

**To update status:**
1. Open order details
2. Click status dropdown
3. Select new status
4. Add notes if needed
5. Click "Update Status"
6. Customer notified automatically

### Assigning Delivery Agents

1. Open order details
2. Click "Assign Agent"
3. Select from available agents
4. Agent notified automatically
5. Order status updated

### Processing Refunds

1. Open order details
2. Click "Request Refund"
3. Select refund reason
4. Enter refund amount
5. Process refund
6. Customer notified

### Canceling Orders

⚠️ **Warning:** Cancellation cannot be undone!

1. Open order details
2. Click "Cancel Order"
3. Select cancellation reason
4. Confirm cancellation
5. Refund processed automatically
6. Customer notified

### Bulk Order Operations

**Export Orders:**
1. Go to "Orders" → "Export"
2. Select date range
3. Choose format (CSV, Excel, PDF)
4. Download file

**Print Invoices:**
1. Select orders to print
2. Click "Print Invoices"
3. Choose format (single/multiple)
4. Print or save as PDF

**Update Multiple Orders:**
1. Select multiple orders
2. Choose action:
   - Update status
   - Assign agent
   - Add notes
3. Apply to all selected
