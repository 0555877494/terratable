## 🎨 Logo Specifications

### Technical Details
- **Format**: SVG (Scalable Vector Graphics)
- **ViewBox**: 200x200 units
- **Colors**: 
  - Gradient: #f59e0b → #d97706 → #b45309
  - Leaf: #10b981 → #059669
  - Elements: White (#ffffff)
- **Elements**:
  - 4 fork tines (vertical rectangles)
  - Fork base (horizontal rectangle)
  - Fork handle (vertical rectangle)
  - Leaf accent (curved path)
  - Leaf vein (decorative line)
  - Outer ring (subtle accent)

### Design Elements
1. **Fork Tines**: Represent dining/food
2. **Fork Base**: Stability and foundation
3. **Fork Handle**: The "T" for Terra & Table
4. **Leaf**: Fresh, organic, natural
5. **Gradient Circle**: Premium, warm, inviting
